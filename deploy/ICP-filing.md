# worddrop ICP 备案材料清单与流程指引 (ICP filing guide)

本文档面向把 worddrop 自托管服务（rendezvous + relay）部署在**中国大陆服务器**
（本仓库场景为腾讯云）并绑定了域名的场景。依据中国大陆法规，解析到大陆服务器的
域名必须完成 ICP 备案；本文档给出**个人备案**所需的材料清单与操作流程。备案是
**域名持有者本人**的操作，本文档只是材料清单与指引，不代替腾讯云控制台的实际流程。

> 本仓库公共演示服务使用的 `worddrop.cloud` 目前**未备案**，大陆来源访问被腾讯云
> 拦截（见 §1），本文档即针对该场景的补齐步骤。个人备案免费，备案本身不产生费用
> （域名、服务器费用另计）。

---

## 1. 为什么需要备案

- **法规要求**：解析到中国大陆服务器的域名，必须完成 ICP 备案。备案由服务器接入商
  （腾讯云）代为提交至各省通信管理局审核。
- **未备案的拦截表现**（本机实测排查结论）：腾讯云会对**大陆来源 + 域名 SNI** 的
  TCP 80/443 流量做拦截，具体如下表：

| 流量路径 | 未备案时的表现 |
| :--- | :--- |
| 大陆来源 + 域名 + TCP 80 | 返回 302，跳转到备案提示页 |
| 大陆来源 + 域名 + TCP 443 | 连接被重置（RST） |
| 海外来源 + 域名 | 不受影响，正常访问 |
| 域名 + QUIC/UDP | 不受影响（拦截只针对 TCP 80/443） |
| IP 直连（不填域名） | 不受影响 |

- **结论**：客户端只要走 `https://relay.你的域名` / `https://pair.你的域名`，
  大陆用户就会被拦。这正是 worddrop.cloud 目前大陆不可达的原因。**海外来源、
  QUIC/UDP、IP 直连都不受影响**，可作备案期间的临时验证手段（见 §5）。

---

## 2. 个人备案材料清单

| 材料 | 获取方式 | 说明 |
| :--- | :--- | :--- |
| 身份证（正反面照片） | 本人 | 备案主体为个人；身份证号（填写你的身份证号） |
| 手机号 | 本人 | 接收管局短信核验与审核通知（填写你的手机号） |
| 邮箱 | 本人 | 接收备案进度通知（填写你的邮箱） |
| 域名实名认证截图 | 域名注册商后台 | 证明域名已实名，且持有者信息与备案主体一致 |
| 服务器公网 IP | 腾讯云控制台 | 备案接入的服务器 IP（你的服务器公网 IP） |
| 接入商信息 | 腾讯云 | 服务器在腾讯云（大陆），接入商即腾讯云 |

---

## 3. 备案流程步骤

1. 登录腾讯云控制台，搜索/进入「ICP 备案」入口。
2. 按引导开始备案，填写**主体信息**（个人：姓名、身份证、手机号、邮箱）。
3. 填写**网站信息**（域名、网站名称、服务内容等）。
4. 上传**材料**（身份证照片等，按页面提示）。
5. 提交，经腾讯云初审后上报**省通信管理局**审核。
6. 管局审核时长约 **1-3 周**（各省不同），通过后发放备案号。

> 具体页面名称、按钮位置与材料格式要求，以腾讯云控制台实际流程为准。
> 若备案系统提示后续还需其他核验步骤（如公安备案），同样以腾讯云控制台实际流程为准。

---

## 4. 域名注册商处需要确认的填写项

- **域名持有者实名信息须与备案主体一致**：个人备案时，域名持有者的姓名与身份证号
  （填写你的身份证号）必须和备案主体完全一致，否则备案会被驳回。
- **域名在有效期内**：过期或即将过期的域名无法完成备案，先续费再备案。
- **DNS 解析在备案期间的注意事项**：域名需保持解析到备案接入的腾讯云服务器；
  审核期间大陆访问会看到腾讯云的备案提示页（§1 的 302），属正常状态。
  若管局或腾讯云对页面核验有额外要求，以腾讯云备案系统提示为准。

---

## 5. 备案期间注意事项

- **大陆无法访问该域名服务**：备案完成前，80/443 的域名流量持续被拦截，属预期。
- **临时验证方式**：可用海外 IP/代理访问（海外来源不拦截），或直接用服务器 IP 直连
  （无域名不受影响）；正式使用请等待备案完成。
- **建议保持服务低调**：备案审核期间避免对外宣传、避免服务被高频扫描，降低被举报
  或干扰的风险。

---

## 6. 备案通过后切回自用

备案通过后，把客户端配置指回自己的域名（两端都要设置，CLI 与 GUI 通用）：

```sh
worddrop config set relay_url https://relay.你的域名
worddrop config set rendezvous_url https://pair.你的域名
worddrop config get
```

环境变量等价写法：

```sh
export WORDDROP_RELAY_URL=https://relay.你的域名
export WORDDROP_RENDEZVOUS_URL=https://pair.你的域名
```

验证：

```sh
curl -fsSL https://relay.你的域名/          # "Iroh Relay" 页面
curl -fsSL https://pair.你的域名/health     # ok
```

> 前置条件：服务器防火墙放行 80/443 TCP（见 `deploy/README.md` §3）；TLS 证书由
> Caddy 自动向 Let's Encrypt 申请（见 `deploy/README.md` §4），备案不涉及证书。
